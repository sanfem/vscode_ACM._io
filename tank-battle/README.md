# Tank Battle (Swing)

Small fixed-view tank battle game built with Java Swing. The map is a compact pixel-style grid and includes five levels.

## Run

```bash
cd tank-battle
mvn -q -DskipTests package
java -cp target/classes io.github.sanfem.tankbattle.App
```

## Controls

- Arrow keys: move
- Space: fire
- Enter: next level / restart
